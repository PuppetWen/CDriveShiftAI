# CDriveShiftAI v0.2.0

版本规则：每个点分隔的数字段只使用0–9，之后依次发布0.2.1、0.2.2，0.2.9之后进位为0.3.0。安装包内版本、Git标签和更新元数据同步采用此规则。

本版汇总 v0.1.8 之后的更新检查修复、强制删除改进、多关键词搜索、实时搜索优化和结果选择交互。

## 更新检查与强制删除

- 修复 FlClash 等共享代理出口触发 GitHub 匿名 API 限流后更新检查持续403：自动通过 GitHub 官方 Release 清单检查版本，合并并发检查并遵守限流冷却；下载继续校验文件大小和 SHA-512。
- 修复普通 PowerShell 占用被误判为禁止结束的问题；核验进程身份后处理已确认的占用，支持停止可停止且独占进程的第三方服务，重试短暂非空目录并保留失败子路径。
- 新增使用已配置 AI 分析占用原因，依据实际检测证据给出建议；AI 输出不作为命令执行，系统目录、关键进程与迁移事务保护继续生效。

## 搜索与后台性能

- 文件名、文件夹名和文件内容均支持多个可编辑关键词；按“或”关系显示每个关键词的结果并集，同一项只显示一次。
- 恢复 OR 查询索引预筛，减少重复字符串转换与排序；连续输入只保留当前及最新查询，输入法组词暂停搜索，结果更新让位于输入。
- 目录大小等待输入停顿后仅统计可见行，采用有界缓存与扫描预算。隐藏或最小化窗口取消查询和目录统计，后台索引暂停，不增加后台轮询。

## 输入与结果选择

- 关键词草稿为空时，Backspace 或 Delete 删除前一颗完整标签；可连续删除。草稿有文字时保留正常字符删除，中文输入法组词不误删标签；达到32词上限后输入框仍可聚焦删除。
- 搜索框与标签编辑使用跟随主题的柔和荧光，保留高对比模式焦点反馈，不使用循环动画。
- 关键词提示精简为“回车确认关键词，点击标签可编辑”。
- 名称与内容搜索均支持 Ctrl 加左键切换选择、拖动框选、Ctrl 累加框选。框选支持边缘自动滚动和跨虚拟行选择，结束拖动不会误打开文件，按钮与滚动条不触发框选。
- 框选事件只在手势期间监听，持续帧回调仅用于拖动中的边缘滚动；隐藏、失焦、更换查询或结束手势后取消。不增加后台轮询。
- 多选保持按路径去重；刷新时移除已消失的选项。右键菜单仍针对所点项目，多选时避免原单项 Delete/F2 快捷键误操作。本次没有增加批量删除功能。
