# CDriveShiftAI 0.1.10

多关键词搜索统一使用 **OR（或）**：输入 `dsh` 和 `deep`，显示命中 `dsh` 的结果与命中 `deep` 的结果的并集；同时命中两词的文件或文件夹只显示一次。

- 文件夹、文件名称和文件内容采用相同规则。
- 输入实时查询、回车生成标签、点击标签编辑的交互保持可用。
- 移除“全部/任一”选择；旧书签与保存的搜索状态自动转为 OR，旧交集快照重新查询。
- 在原生查询层合并结果后排序、分页，避免每个词只搜部分结果后再拼接造成遗漏或重复。

验证覆盖：前端/Electron 类型检查、搜索和存储单测、原生索引测试、真实文件/正文的并集与去重、浏览器标签交互，以及旧书签和独立窗口恢复。

本地交付在 `release-v0.1.10/`：`CDriveShiftAI-x64.exe`、`CDriveShiftAI-x64-portable.exe` 和 SHA-512 清单 `update-manifest.json`。使用现有 E 盘工具及项目缓存构建，不发布到 GitHub。
