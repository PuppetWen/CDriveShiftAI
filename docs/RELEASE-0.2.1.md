# CDriveShiftAI v0.2.1

本版修复自动更新过程中的目录占用和临时路径继承，并在新版主窗口真正加载、显示后确认更新成功。

## 自动安装与重新打开

- 修复更新助手继承应用数据目录作为工作目录，导致助手自身阻止数据目录移动的问题。直接启动、备用助手及 PowerShell 启动都固定使用更新暂存目录，原生助手也会主动释放继承的工作目录。
- 为更新助手和静默安装器明确设置暂存目录内的 `temp`，通过子进程环境传递 `TEMP`、`TMP`，不修改主进程全局环境。
- 新版及回滚程序从更新暂存目录外启动，使用应用数据目录内长期存在的 `temp`；兼容自定义数据目录，避免更新清理后临时路径失效或目录被自身占用。
- 更新启动时打开主窗口，主页面完成加载且窗口可见、未最小化后才写入成功标记。加载失败、提前关闭、隐藏或渲染进程退出均不提前确认成功；普通启动仍清理旧版助手目录。
- 保留下载大小与 SHA-512 校验、应用数据保留及原有启动失败回滚流程。

## 验证

- Electron TypeScript 检查通过；4个更新相关测试文件、30项测试通过，覆盖更新检查、下载、助手启动及窗口成功回执。
- 7项 Rust 更新器测试通过，覆盖安装器工作目录与临时环境、新版启动目录和自定义数据目录。
- 在隔离目录复现旧助手继承应用数据目录后无法移动该目录的自锁问题。
- 隔离便携版完成从0.1.12下载 GitHub 0.2.0、校验、替换并自动打开新版的真实升级链路测试。该测试验证旧版兼容与真实下载交接，不等同于已有 D 盘安装目录的现场安装验证。
- `git diff --check` 通过。

- `CDriveShiftAI-x64-portable.exe`：Windows x64 单文件便携版。
