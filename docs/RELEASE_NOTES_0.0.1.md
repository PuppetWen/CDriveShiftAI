# CDriveShiftAI 0.0.1

首个公开测试版本。

## 主要功能

- 自研全盘名称索引，不依赖 Everything；优先读取 NTFS MFT，失败时降级为并行目录扫描。
- 支持名称、路径、正则、文件类型、扩展名、大小、时间、盘符和多条件组合筛选。
- 指定目录全文索引与内容搜索。
- 磁盘目录归属地图、本机应用资产识别和可选 AI 二次分析。
- 跨盘目录迁移、符号链接/目录联接、事务记录、恢复与再次迁移。
- 三套主题、独立极速搜索窗口、托盘菜单、全局快捷键和搜索书签。
- GitHub Release 更新检查；只在打开界面时检查，不在托盘后台循环联网。

## 性能修复

- 所有窗口隐藏或最小化时暂停全量名称索引、内容索引和递归变更重活，回到前台后继续。
- 隐藏状态同时暂停 Canvas 与 CSS 动画。
- 名称索引改用只读内存映射、紧凑元数据和固定大小名称签名。
- 本机 5,772,880 条索引实测：常驻工作集约从 1,494 MB 降到 100 MB，私有提交约从 1,752 MB 降到 455 MB；普通名称查询约 16.7 ms。
- 强制全量重建在前台约占用 3.1 个核心；切到后台后实测约 0.01%（任务管理器总 CPU 口径）。

## 下载

- `CDriveShiftAI-x64.exe`：安装版，首次安装可选择路径；后续版本沿用现有安装路径覆盖升级。
- `CDriveShiftAI-x64-portable.exe`：单文件便携版。

## 注意

当前二进制未使用商业 Authenticode 证书，Windows 可能显示 SmartScreen“未知发布者”提示。目录迁移属于高风险文件操作，请先退出相关应用并确认有可用备份。
