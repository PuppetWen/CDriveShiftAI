# 管理员强制删除与资源管理器右键菜单（2026-09-10）

## 使用方式

在软件内选择“强制永久删除”并确认后，先按当前权限删除；必要时结束本次预检列出且身份未变的普通相关进程并重试。仍因权限、占用或持续写入失败时，自动尝试管理员 PowerShell。Windows 弹出 UAC 时选择“是”；取消授权会明确报告，重新执行需重新预检与确认。

在“设置 → 索引与快捷操作 → 资源管理器右键菜单”中启用或关闭“CDriveShiftAI 强制删除”。启用后，在资源管理器右键选择文件或文件夹即可打开同一个删除预检窗口。Windows 11 可能需点击“显示更多选项”。连续请求会排队，正在确认或执行的目标不会被替换。菜单读取实际注册状态；程序位置改变或注册不完整时提示关闭后重新开启。

## 实现及修复

- 普通与管理员删除共用固定 PowerShell 脚本，通过 Windows 文件句柄校验并删除目标。权限提升只作用于辅助进程；普通尝试不弹 UAC。
- 已获授权的辅助进程使用 Windows 备份/还原特权处理可处理的 ACL 限制，不永久改写目标或外部文件的所有者、ACL。
- 删除前后检查预检的卷号、文件 ID、创建时间、链接类型及规范路径。操作期间固定父目录和目标句柄，不跟随 junction 或符号链接删除外部内容。
- 修复原 Node.js `fs.rm` 在只读硬链接上清除属性，可能连带影响目标外硬链接的问题。现在使用句柄删除标志，保留外部链接的内容和只读属性。
- 提权后仅再次处理普通权限未能结束、预检已确认且身份仍匹配的进程；不按进程名称批量结束，也不结束未确认的子进程。
- UAC 取消、权限仍被拒绝、文件锁、路径被替换、目录持续写入均报告实际结果。命令返回成功后还会检查目标确实不存在。
- 路径及进程数据编码传递，脚本不依赖可被替换的临时 `.ps1` 文件，不将用户文件名当成命令执行。
- 菜单仅使用两个本软件专属的当前用户注册表项。设置和注册表更新组成事务；写入、验证或保存失败时恢复先前注册信息。卸载仅清除归属当前安装的菜单，升级保留菜单。
- 冷启动、二次启动、托盘恢复通过主进程队列向窗口递交请求。修复弹窗打开时后台搜索快捷键可能触发删除的问题，搜索结果在删除成功后同步移除。

## 能力边界

强制删除不是“任何文件都一定能删除”。PowerShell 的 `-Force` 本身不能越过所有安全限制，提升权限也不代表能够解除驱动或受保护进程持有的所有独占锁。新辅助模块面向本机普通绝对路径，保留系统、应用自身以及迁移事务路径保护；对无法确认身份的路径停止操作。管理员仍失败时保留重启、应用卸载、安全模式等具体指引，不自动重启，也不把尚未删除的文件报告成成功。

官方依据：[PowerShell Remove-Item](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/remove-item)、[Windows 文件安全与访问权限](https://learn.microsoft.com/en-us/windows/win32/fileio/file-security-and-access-rights)、[资源管理器静态菜单](https://learn.microsoft.com/en-us/windows/win32/shell/context)、[Windows 11 右键菜单](https://blogs.windows.com/blog/2021/07/19/extending-the-context-menu-and-share-dialog-in-windows-11/)。

- `npm run test:force-delete`：完整服务实际识别并结束测试占用进程、删除目标，保留目标外 junction 内容和只读硬链接属性。
- `npm run test:force-delete-guidance`：70 项界面检查，包括 UAC 等待/取消/失败/成功和菜单开关状态、失败恢复。
- `npm run test:force-delete-app-queue`：13 项真实 App 组件检查，包括 StrictMode、排队、重复请求、属性框叠加和键盘事件。
- `npm run test:explorer-launch`：实际 Electron 主进程、preload 和构建后页面完成冷启动、二次启动、托盘恢复及独立确认测试。
- `npm run test:explorer-registry`：在专用随机注册表测试命名空间实际添加、移除及恢复菜单数据，测试后清理；未修改用户真实资源管理器菜单。
- `npm run test:main-lifecycle`：验证设置与菜单事务失败回滚、设置串行应用及退出等待。
- `npm run lint`、前后端构建及 Git 差异检查通过。

UAC 弹窗的允许/取消返回使用注入测试；没有实际触发本机 UAC 或删除真实应用。真实文件和注册表测试均使用隔离测试数据。复用已有 Node、Electron、Windows PowerShell 和本地依赖，没有下载新增依赖。
