# CDriveShiftAI 0.1.0 发布说明

本版本重新调整鼠标快捷操作的时间范围，并将字体与界面大小改为连续百分比滑杆。

## 鼠标快捷操作

- 长按时长范围由 500–10000 毫秒改为 0–3000 毫秒，步进为 100 毫秒。
- 0 毫秒表示按下已配置的鼠标后退侧键、前进侧键或中键后立即触发。
- 前端设置、持久化存储与 Rust 原生 Raw Input 监听器使用相同范围。
- 旧配置中大于 3000 毫秒的时间会自动调整到 3000 毫秒，不会造成配置读取失败。

## 字体与界面大小

- 原有四档大小按钮改为连续滑杆，以此前的“标准”字体和界面大小为 100%。
- 可在 50%–300% 范围内来回拖动，每次变化 10%，不是按钮选择。
- 文字、控件、间距和图标整体缩放，主窗口、极速搜索及辅助窗口同步生效。
- 拖动时界面和文字跟随滑块逐步放大或缩小，松开或键盘调整结束后自动保存最终值。
- 旧版本中的比例会归一到最近的 10%。

## 历史更新

- 更新与诊断继续提供逐条独立折叠的离线历史记录。
- 历史列表超过可视区域时显示独立滚动条，支持鼠标滚轮和键盘下滑。
- v0.0.12 已加入历史更新列表。

## 验证

- 63 项 TypeScript 单元测试通过。
- 索引器 9 项和更新器 4 项 Rust 原生测试通过。
- 50%–300% 与 0–3000 ms 设置页滑杆布局、范围和滚动能力检查通过。
- Windows 安装版与便携版构建、单文件便携运行和干净退出冒烟验证通过。

## 下载

- `CDriveShiftAI-x64.exe`：Windows x64 安装版，可选择安装目录。
- `CDriveShiftAI-x64-portable.exe`：Windows x64 便携版。
- `update-manifest.json`：包含安装版和便携版 SHA-512 校验值的更新清单。
- `latest.yml`：Electron 更新元数据。
