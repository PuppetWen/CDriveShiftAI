# CDriveShiftAI 0.1.6

本版修复强制删除确认框点击后看似没有反应的问题，并让资源管理器右键删除只打开独立确认窗口。

## 确认框反馈

- 修复复选框被通用样式隐藏的问题；点击整行即可勾选或取消，勾选后立即显示对勾、高亮和“已勾选确认”。
- 底部提示先勾选再点击删除，按钮随确认状态启用；支持空格切换和可见的键盘焦点。
- 执行删除或等待管理员授权时显示进度状态并禁止重复操作；勾选本身不会执行删除。

## 独立删除窗口

- 从资源管理器右键启动时只弹出删除确认窗口，不打开或唤起桌面端主界面。
- 支持程序未启动、主界面已打开及托盘运行场景，连续请求继续逐项排队确认。
- 删除成功后显示结果；失败时保留原因、路径及操作指引，重试需要重新检查和确认。
- 已注册的右键菜单无需重新添加。

## 下载

- `CDriveShiftAI-x64.exe`：Windows x64 安装版。
- `CDriveShiftAI-x64-portable.exe`：Windows x64 便携版。
- `update-manifest.json`：供应用内自动更新使用的文件大小与 SHA-512 校验清单。
