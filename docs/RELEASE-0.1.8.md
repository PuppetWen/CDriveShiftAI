# CDriveShiftAI v0.1.8

本版改进被占用文件、文件夹的检测与强制删除，并减少搜索索引对移动、删除操作的干扰。

## 更新内容

- 删除前展示所属应用、进程名、PID、程序位置与可识别的占用路径，区分实际占用句柄和命令行关联。
- 新增系统文件句柄扫描，补充超过 5000 项目录遍历上限的占用；CIM 查询失败时仍可使用原生进程身份识别应用。
- 排除可能阻塞的命名管道查询；检测超时时保留已完成结果，并提示列表可能不完整。
- 用户确认后，普通删除失败时重新核对占用进程身份，只处理已确认、身份一致且允许结束的进程；必要时提权重试并核验删除结果。
- 应用和索引子进程使用应用数据目录作为工作目录，避免继承需要删除或移动的目录。
- 名称与内容扫描在后台暂停、读取内容及等待队列前释放目录枚举句柄；实时搜索和目录统计同步释放枚举句柄。
- 内容读取允许共享读写、删除，并限制实际读取字节数，避免增长中的日志突破单文件大小限制。

## 使用提示

结束占用应用可能丢失未保存的工作，请先保存内容。Windows 受保护进程、驱动锁或持续重新创建的文件仍可能无法删除，程序会保留具体失败原因；系统目录和迁移事务保护继续生效。

## 下载

- `CDriveShiftAI-x64.exe`：Windows x64 安装版，已有安装沿用原目录升级。
- `CDriveShiftAI-x64-portable.exe`：Windows x64 单文件便携版。
- `update-manifest.json`：自动更新清单，包含安装包和便携包的大小及 SHA-512 校验值。
- `latest.yml`、`CDriveShiftAI-x64.exe.blockmap`：安装版更新元数据。

## 验证

已通过真实独占文件锁、终端当前目录锁、超过 5000 项目录的占用识别、CIM 不可用时的确认删除，以及索引运行和后台暂停期间移动、删除目录的检查。构建、删除界面检查和原生测试通过。

本机全量回归中的 NTFS 权限复制测试仍有一项失败，修改前版本也能复现；本版未修改迁移权限复制逻辑。
