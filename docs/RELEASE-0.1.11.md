# CDriveShiftAI 0.1.11：实时搜索与后台占用

交付位于 `release-v0.1.11/`，包含安装包、便携包及 SHA-512 清单。本次没有发布到 GitHub。

## 主要改动

1. 修复多关键词改为 OR 后跳过索引签名预筛的性能退化：恢复逐词候选并集预筛，保留短词、中文和 Unicode 正确性。
2. 分页只选取所需的 top-K 候选，避免反复完整排序；ASCII 名称和路径比较不再反复创建临时字符串。
3. 名称/内容查询防抖改为45/90毫秒。连续输入只保留当前和最新待处理请求，输入法组词期间暂停查询，回车将同一查询变成标签不会再查一遍。
4. React 结果更新让位于输入；旧响应不能覆盖新查询或已清空结果。修复旧筛选状态中空数组引用变化可能引起的重复查询。
5. 文件元数据采用5秒、最多4096条的缓存，索引变动时失效；正文搜索直接复用索引返回的时间和大小。
6. 停止输入700毫秒后，仅统计当前可见目录，每批最多24项，自动扫描限2秒/25000项；不完整统计显示“≥”。显式属性查看保留25秒/100万项预算，不使用不完整缓存。
7. 隐藏或最小化窗口取消搜索及目录统计，原生后台索引继续暂停，不增加轮询。关闭主窗口时仍可用可见的独立搜索窗口。

## 测量结果

原生基准：独立生成100万条索引，各查询预热后测5次，以下为中位数，首批返回240项。

| 查询 | 优化前 | 优化后 |
|---|---:|---:|
| 单词，100个命中 | 16.34ms | 5.27ms |
| 多词OR，200个命中 | 19.96ms | 7.21ms |
| 多词OR，约100万个命中 | 332.70ms | 102.50ms |
| 单字符，约100万个命中 | 204.45ms | 86.26ms |
| 名称排序，约100万个命中 | 132.28ms | 37.73ms |

界面基准：真实 React/浏览器，API 使用固定10毫秒替身，每项16个样本。输入到结果下一帧的名称搜索 p50 从140.6降到90.7毫秒，p95从173.3降到114.2毫秒；内容搜索 p50从212.9降到121.2毫秒，p95从216.1降到129.8毫秒。这组数字衡量界面响应，不包含实际磁盘/原生查询延迟。

整个打包应用的托盘测试：隔离复制约528.5MB真实索引，两版本均先显示10秒，关闭到托盘后等待2秒，再采样约6.52秒。0.1.10与0.1.11的进程树 CPU 增量均为0，渲染进程数量均为0；工作集分别约16.99/17.06MiB。0.1.11私有提交内存约502.9MiB，不能将工作集当成全部内存占用。两版在关闭前尚未报告索引加载完成，因此该测试验证的是加载中转托盘会暂停，不能代表完整索引加载后的全部内存状态。没有把约18.9MiB的私有内存波动归因为本次改进。

另用隔离256文件索引采样后台6.22秒，原生进程 CPU 增量为0、工作集28.86MiB。以上都是本机样例，不保证所有设备或持续文件变更时的占用完全相同。

## 验证

- 前端与主进程 TypeScript、生产构建通过。
- 搜索调度、索引通知、刷新策略、虚拟列表、存储和搜索帮助共29项测试通过。
- 15项Rust测试通过，覆盖短词/Unicode OR、12000条候选的分页排序一致性、ASCII与Unicode比较等价性。
- 真实文件、文件夹、正文OR、去重、分页、模糊、整词、正则和中文测试通过。
- 浏览器验证连续输入只查最终词、IME组词暂停、标签提交不重复查询、隐藏静默、恢复刷新、过期结果丢弃和可见目录批量限制。
- 便携包启动和正常退出通过；确认包内为0.1.11，并包含本次验证的原生索引器和新调度器。

可复现脚本：`scripts/benchmark-keyword-search.mjs`、`scripts/smoke-search-responsiveness.mjs`、`scripts/smoke-search-idle.mjs`、`scripts/smoke-packaged-idle.mjs`。测试样例与应用资料均隔离在项目内，没有修改真实索引或用户内容；编译继续使用现有 E 盘环境和项目缓存。
