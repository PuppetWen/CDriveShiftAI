# CDriveShiftAI 0.1.4

本版修复跨盘迁移、迁回和再次迁移的数据校验与恢复问题，新增管理员 PowerShell 强制删除及资源管理器右键菜单开关，并完善删除失败指引和设置保存。

## 迁移与恢复

- 逐文件校验内容、目录结构和链接，复制并核验 NTFS 访问权限，识别复制期间的写入变化。
- 修复内部绝对链接、外部相对链接在迁移或迁回后指向错误位置的问题，正确识别 Windows 8.3 短路径，并核对原路径是否被替换。
- 修复部分清理失败和中断恢复误判，保留可用数据与待清理状态；恢复后可以再次迁移。
- 保留仍在使用或含待恢复数据的迁移记录，防止丢失迁回入口。

## 管理员 PowerShell 强制删除

- 用户确认后先常规删除，必要时处理已确认且身份未变的普通占用进程；仍失败时自动请求管理员 PowerShell 重试。
- 明确显示 UAC 等待、取消及执行结果，删除后检查目标确实不存在。
- 删除时核对目标和父目录身份，不跟随链接删除外部内容，不改写目标外硬链接的只读属性。
- 系统、应用自身和迁移事务路径继续受保护；管理员权限无法解除所有驱动锁或系统限制。

## 删除失败操作指引

- 按文件占用、权限拒绝、后台持续写入和受保护路径分别说明下一步，保留错误码及失败路径。
- 提供定位文件、复制路径、任务管理器和已安装应用入口，以及重启、卸载和普通残留文件的安全模式说明。
- 重试需要重新预检与确认，不将尚未删除的目标报告为成功。

## 资源管理器右键菜单

- 在“设置 → 索引与快捷操作 → 资源管理器右键菜单”添加或取消“CDriveShiftAI 强制删除”。
- 支持文件和文件夹，Windows 11 可能需点击“显示更多选项”；选择菜单后进入同一预检确认窗口。
- 支持冷启动、托盘恢复和连续请求排队，正在确认或执行的目标不会被新请求替换。
- 显示实际注册状态，设置失败时回滚；升级保留菜单，卸载仅清理由当前安装拥有的菜单。

## 配置与界面稳定性

- 修复设置并发保存覆盖新编辑、旧请求覆盖新配置等问题，配置读取或保存失败明确报错并保留原数据。
- 迁移、恢复和文件操作互斥，退出等待正在执行的事务；修复连续迁移状态和过期预检问题。
- 修复弹窗期间后台搜索快捷键误触发删除的问题，改善长路径及大字号下的删除提示布局。
- 扩展迁移往返、文件权限与链接、文件占用、菜单注册、请求排队和失败恢复的自动化回归覆盖。

## 下载

- `CDriveShiftAI-x64.exe`：Windows x64 安装版，可选择安装目录。
- `CDriveShiftAI-x64-portable.exe`：Windows x64 便携版。
- `update-manifest.json`：安装版和便携版的文件大小与 SHA-512 校验清单，供应用内自动更新使用。
