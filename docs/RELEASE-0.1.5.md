# CDriveShiftAI 0.1.5

本版修复程序已运行时右键强制删除误报“绝对路径无效”的问题，并补充 PowerShell 等进程持有目录句柄的占用检测。

## 右键强制删除

- 程序已运行或最小化到托盘时，通过资源管理器右键选择的目标可以正确传入删除预检窗口。
- 修复 Electron 二次启动参数重排造成的路径错位，继续保留用户确认和连续请求排队。
- 已注册的右键菜单无需重新添加。

## PowerShell 与目录占用

- 新增目录句柄占用检测，识别 PowerShell 已 `cd` 进入待删除目录的情况，包括空目录。
- 预检展示占用进程，用户确认后再次核对身份，仅处理可结束的普通相关进程，不按名称批量结束 PowerShell。
- 保留管理员重试和删除结果核验；驱动锁或系统限制仍可能阻止删除，失败时提供具体操作指引。

## 回归覆盖

- 新增真实 Electron 进程二次启动测试，验证已有窗口与托盘场景的路径传递。
- 新增 PowerShell 当前目录占用测试，覆盖空目录、进程身份核对和用户确认后的删除流程。

## 下载

- `CDriveShiftAI-x64.exe`：Windows x64 安装版。
- `CDriveShiftAI-x64-portable.exe`：Windows x64 便携版。
- `update-manifest.json`：供应用内自动更新使用的文件大小与 SHA-512 校验清单。
